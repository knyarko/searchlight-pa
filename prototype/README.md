# Prototype — evidence-first hero

A third variant of the home page, testing one idea: **the hero visual is the
product's own output, not a photograph.**

- replica — <https://knyarko.github.io/searchlight-pa/>
- redesign — <https://knyarko.github.io/searchlight-pa/redesign/>
- this — <https://knyarko.github.io/searchlight-pa/prototype/>

Home page only. The nav and footer link across to the redesign's inner pages,
which keep their full-bleed photographic banners — the hybrid this was meant to
test, rather than a wholesale replacement.

## Why

A survey of the sector (Watermark, Civitas Learning, HelioCampus, Nuventive,
Explorance, Weave, EAB, Ellucian) found that none of them lead with a
photographic hero. The strongest of them, [Civitas Learning](https://www.civitaslearning.com),
puts a real statistical chart where the hero image would go — effect sizes with
confidence intervals, labelled by cohort. It is the most self-assured thing in
the category, because it shows the product doing its job instead of describing it.

SearchLight already has the equivalent, and better: a real Performance Review.

## The data is real

Both artifacts are rebuilt from SearchLight's own product deck
(`Presentations & Demo Material/SearchLightPA - Overview - 11.15.15.pdf`,
the "Performance Review (Tabular)" and "Faculty Course Assessment Reports" slides).
Nothing here is invented.

**Hero chart** — four ABET program outcomes as 100% stacked columns on the
product's real four-point scale (1 Unacceptable, 2 Needs improvement, 3 Meets
expectation, 4 Exceeds expectation), with its threshold line at 25%. The
distributions are the deck's: outcome (b) 0 / 1 / 46 / 25, (f) 3 / 14 / 24 / 142,
(g) 14 / 69 / 257 / 276, (k) 10 / 145 / 244 / 280. Grand total 27 / 229 / 571 / 723.

**FCAR card** — the Faculty Course Assessment Report for EEGR202.001 Electric
Circuits, Spring 2011: its real grade distribution (8/2/2/0/0/2/0, total 14) and
its four performance criteria with E/A/M/U counts totalling 31 / 15 / 5 / 5.
The instructor's name is on the original slide and is deliberately left off here.

It is drawn in HTML and CSS rather than screenshotted, so it is crisp, themes with
the rest of the site, reads on a phone, and carries a hidden data table for screen
readers — and it does not show the 2012-era interface chrome around the original.

## Two things this prototype does not do

1. **No logo wall.** The sector treats named institutions as table stakes —
   HelioCampus puts six above the fold. `Accounts/Client List.xlsx` holds one
   institution (Morgan State University) and a handful of internal department
   contacts, so there is nothing to build a wall from yet, and those contact names
   are personal data that should not be published. If more institutions can be
   named with their permission, this is the highest-value addition to any of the
   three variants.

2. **No pain-led headline.** Every competitor opens with the customer's problem
   ("You have more data than ever. And less clarity than you need."), where
   SearchLight opens with a capability list. Changing that means writing new
   claims, so the copy here still comes from the existing site. It is worth doing
   — in your words, not mine.
